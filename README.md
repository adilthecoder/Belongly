# Belongly Landing Page

A polished product landing page for **Belongly** — a local-first Android app that remembers where your belongings are, who has them, and when they should come back.

## Highlights

- Responsive light and dark themes
- Animated product-story experience
- Interactive search and memory examples
- Shelf B brand mark rendered directly in CSS
- No early-access or pricing flow
- Local-first product messaging

## Run locally

Requirements: Node.js 22.13 or newer and pnpm.

```bash
pnpm install
pnpm dev
```

Open the local address printed by the development server.

## Production build

```bash
pnpm build
pnpm start
```

## Useful commands

```bash
pnpm dev     # Start the development server
pnpm build   # Create a production build
pnpm lint    # Run lint checks
pnpm start   # Serve the production build
```

## Project structure

```text
app/          Page, layout, and visual styles
```

## Product principles

Belongly is designed to feel like a friendly memory aid rather than an inventory system. The MVP is Android-first, works without an account, stores data locally, and supports manual backup and restore.

## Status

Landing page prototype. Product downloads, signup, pricing, and early-access registration are intentionally not included yet.
